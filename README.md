# SongDraft

**把一句歌词，变成别人能听懂的 Demo。**

SongDraft 是一个面向词曲创作者的轻量灵感工作台。
你只需要写下一句歌词、一个故事或一段创作想法，它就能帮你整理成创作简报、写出歌词草稿，并生成两版可以直接试听的 Demo，再通过一个私密链接或二维码发给合作方试听、评论。

---

## 它解决什么问题

音乐人的灵感常常散落在语音备忘录、聊天记录、零散图片和文档里。当真正需要和编曲、制作人或企划沟通方向时，你会反复遇到这些麻烦：

- 💭 灵感和创作背景容易丢失，过两天就想不起当时想要的感觉。
- 🎧 从一句话到「别人能听懂的声音」，制作门槛很高。
- 📁 版本靠文件名管理，分不清哪一版用了什么风格、改在哪里。
- 💬 评论散落在聊天记录里，找不到对应的版本。

SongDraft 把**捕捉、结构化、生成、版本、分享**做成一个短闭环，让「表达一个音乐方向」的成本显著下降。

---

## 核心能力

| 能力 | 你能做什么 |
|---|---|
| ✍️ 灵感记录 | 写下一句歌词或一个想法（1–500 字），系统帮你理解意图。 |
| 📋 创作简报 | 自动整理出主题、情绪、曲风、节奏、人声倾向，全部可手动调整。 |
| 🎵 歌词草稿 | 帮你搭出主歌/副歌结构，保留你的原文，允许任意修改。 |
| 🎚️ 一键生成 Demo | 选择曲风、情绪、速度等参数，一次生成 **A / B 两版**可试听的 Demo。 |
| 🗂️ 版本管理 | 每次生成都有版本记录和参数快照，可设主版本，不再依赖文件名。 |
| 🔗 私域分享 | 一键生成私密链接和二维码，合作方无需注册即可试听。 |
| 💬 评论回流 | 访客在手机上直接留言，评论回到创作端，和对应版本绑定。 |

---

## 为谁设计

- **词曲作者 / 独立音乐人**：十分钟内把一个想法变成可分享的结果，不必学复杂的编曲参数。
- **制作人 / 编曲 / 混音 / 企划**：在手机上快速试听指定版本，留下有上下文的意见，不用下载 App、不用翻聊天记录。
- **运营与评委**：一眼看懂真实问题、AI 价值，以及一条完整的创作协作链路。

---

## 一次完整的创作旅程

1. **写下灵感** ——「雨停以后，我还在旧车站等你」。
2. **得到简报和歌词草稿** —— 自动生成，你可以随时修改。
3. **选择风格并生成** —— 听到 Demo A 和 Demo B 两版方向。
4. **设主版本** —— 选定最满意的一版，参数自动留档。
5. **生成二维码** —— 发给合作方，对方扫码即可试听。
6. **收到反馈** —— 「副歌可以再提前四拍」回到你的项目里。

> 灵感 → 简报与歌词 → Demo 试听 → 版本 → 分享 → 评论，一个闭环。

---

## 适用设备

- **桌面网页**：完整的创作工作台。
- **手机网页**：随时记录灵感、试听与评论。
- **微信内置浏览器**：打开分享页、播放、留言。

## 关于当前版本（透明说明）

SongDraft 目前是一个 Hackathon 阶段的可运行原型，用来验证一条完整的产品链路。

- 当前工作台的候选为**明确标注的模拟结果**，可播放浏览器本地合成的短音阶用于演示交互；它不是外部音乐模型产物，不能视为真实音乐 Demo。
- 已完成的可运行主链路为：认证封装、文字建项目、Project API、Brief/Plan 交互、Mock 存储和受保护上传 API，以及透明 Mock 的版本、私密分享和评论。真实音频、完整素材编辑与外部 Provider 对接仍在迭代，详见 `docs/future-work.md`。
- 后续接入真实的音乐生成能力时，无需改变核心使用方式，但会补全异步任务、音频转存和版本持久化。

我们希望先验证「这套创作工作流是否好用」，再让它发出的声音越来越真实。

## 开发与上线

```bash
pnpm install --frozen-lockfile
pnpm dev
```

未创建 `.env.local` 时，开发环境会自动使用透明的 Auth、Storage、Music Mock，可直接访问。需要接入外部服务时再复制 `.env.example` 并填写配置；配置 `DATABASE_URL` 后项目会写入 PostgreSQL。生产环境不会自动启用 Mock Auth。推荐使用 Node.js 22，发布与真实 COS / DeepSeek / 音乐平台的接入步骤请看 [后续工作与发布手册](docs/future-work.md)。
