- ## Design Brief

  **参考**：v0 全局风格与核心创作台 Prompt
  **覆盖**：SongDraft Web / H5 的全局产品界面
  **审美关键词**：克制、专业、冷静、高信息密度、创作工具感

  ### 布局

  - 桌面端以左侧固定导航 + 顶部工具栏 + 工作区为主。
  - 核心创作台采用“素材 / 操作 / 结果”三栏：左侧构建素材，中间承载关键生成动作，右侧呈现 Creative Brief、生成计划与 Demo。
  - H5 改为单列任务流：当前步骤优先，复杂面板使用底部抽屉或全屏页，不做桌面三栏的生硬缩放。
  - 首页强调一个低压力的中心创作输入器，而非营销型 Hero 区。

  ### 字体

  - 使用系统中文字体栈，英文可使用 Inter。
  - 标题强调层级和字重，不依赖超大字号制造视觉冲击。
  - 信息层级应为：页面标题 > 面板标题 > 字段标签 > 辅助说明 > 元信息。
  - 保持文案短、操作明确；避免“神奇”“一键颠覆”等 AI 营销腔。

  ### 色彩

  - 主背景：白色或微冷白。
  - 表面层：白色；次级背景使用极浅冷灰。
  - 文字：深蓝黑 / 深灰，不使用纯黑大面积铺设。
  - 强调色：低饱和蓝或蓝黑，仅用于主操作、选中态、进度与链接。
  - 边框：细、低对比冷灰；阴影极弱。
  - 禁止渐变发光、霓虹、玻璃拟态、夸张插画与“未来感”装饰。

  ### 间距与形状

  - 采用紧凑但可呼吸的信息密度：表单内间距小于页面区块间距。
  - 卡片圆角应克制，建议 6–8px；主要依靠边框和留白分层，不依赖大圆角卡片。
  - 所有页面按固定间距尺度组织，避免随意的 13px、19px 等零散值。

  ### 组件原则

  - 导航：左侧三段结构——品牌与折叠、主导航、账户与帮助。
  - 面板：白底、细边框、轻圆角；有明确标题、状态和操作区。
  - 按钮：主按钮低饱和深色，次级按钮中性描边；禁用态必须可辨。
  - 素材输入：文本、音频、图片、视频采用同一“素材卡 + 状态 + 分析结果”语言。
  - 生成过程：明确显示输入、能力路由、执行状态、真实/模拟标签和限制，不把 AI 过程包装成黑盒。
  - 音频卡：试听、版本、提供方、生成状态、反馈入口必须在首屏可见。
  - 分享与评论：应延续工具界面，不做社交产品式喧闹反馈；时间戳评论是核心操作，不是附属聊天区。

  ### 需要固化为 Token 的项目

  | 视觉观察            | 建议 Token                                    |
  | ------------------- | --------------------------------------------- |
  | 冷白应用背景        | `color.background.canvas`                     |
  | 白色面板            | `color.surface.default`                       |
  | 浅冷灰分区          | `color.surface.muted`                         |
  | 深蓝黑正文 / 主操作 | `color.text.primary` / `color.action.primary` |
  | 低饱和蓝强调        | `color.accent.brand`                          |
  | 细边框              | `color.border.subtle`                         |
  | 6–8px 卡片圆角      | `radius.md`                                   |
  | 紧凑表单与卡片间距  | `space.2`–`space.4`                           |
  | 页面级留白          | `space.6`–`space.8`                           |

  ### 明确禁止

  - AI 发光渐变、星空/电路板背景、霓虹紫蓝。
  - 大型营销插画、漂浮装饰物、无意义的数据可视化。
  - 超大圆角、厚重阴影、满屏卡片化。
  - 把复杂创作流程伪装为单一“Generate”按钮。
  - 在真实能力和模拟能力之间缺少明确标识。
