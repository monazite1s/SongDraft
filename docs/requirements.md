# SongDraft 产品需求文档

> 版本：V3.0  
> 日期：2026-07-29  
> 产品形态：响应式 Web / 手机 H5  
> 交付约束：24 小时 Hackathon，一名主开发高度依赖 AI Agent，另有测试与运营各一名

## 1. 产品定位

SongDraft 是面向音乐创作者的多模态灵感捕捉与歌曲 Demo 协作工具。

用户可以输入文字描述、歌词、哼唱录音、音频、图片或视频中的任意一种或任意组合。系统保存原始素材，将其整理为可解释、可编辑的 Creative Brief，再根据 Provider 能力生成 Generation Plan 和可试听的歌曲 Demo、配乐 Demo或旋律草稿。

产品解决的是从碎片灵感到可讨论 Demo 的工作流，不承诺直接产出可发行成品。

核心链路：

```text
捕捉灵感 → 分析素材 → 确认创作简报 → 规划生成 → 试听候选
→ 保存版本 → 私密分享 → 时间点评论 → 再次生成 → 导出创作包
```

## 2. 产品原则

1. 一个创作台承载所有输入，不要求用户预选互斥的“词生曲”或“曲生词”模式。
2. 文本、音频、视觉素材至少存在一种，任意非空组合均可进入流程。
3. 原始素材不可被 AI 结果静默覆盖。
4. Creative Brief 和 Generation Plan 必须可解释、可编辑、可确认。
5. 模拟结果不得冒充真实模型结果。
6. 媒体文件真实保存，数据库只保存元数据和对象键。
7. 登录用户拥有项目；访客通过私密分享链接参与评论。
8. Hackathon 只能降低实现深度，不能移除主流程节点。

## 3. 用户与权限

### 3.1 注册用户

- 使用邮箱和密码注册、登录、退出；
- 会话刷新后保持；
- 编辑昵称和头像；
- 创建、查看、复制、归档和删除自己的项目；
- 上传、分析和管理素材；
- 生成 Demo、管理版本和主版本；
- 创建、撤回和更新分享链接；
- 查看并管理项目反馈。

### 3.2 分享访客

- 无需注册，通过有效 Share Token 打开指定版本；
- 试听 Demo、查看允许公开的作品信息和歌词；
- 在允许评论时填写昵称并提交普通评论或时间点评论；
- 不能查看未分享版本、原始私有素材、Provider 配置和内部日志。

### 3.3 登录协作者

P0 不实现复杂项目成员与角色系统。登录用户访问分享页时，评论自动绑定账号；项目所有权仍属于创建者。

## 4. 端型和布局

### 4.1 桌面端

- 左侧全局导航：Logo、首页、创作、作品、设置、用户区；
- 中间主内容区：随路由展示首页、创作台、作品与设置；
- 右侧上下文栏：展示素材详情、Creative Brief、Generation Plan、版本或评论；
- 左侧栏可收起，右侧栏可关闭，主内容区自动扩展。

### 4.2 手机 H5

- 单栏结构；
- 全局导航转换为底部导航或抽屉；
- 上下文栏转换为底部抽屉或全屏页面；
- 创作台改为纵向步骤流；
- 优先保证登录、快速记录、录音、上传、试听、扫码和评论。

### 4.3 页面状态

所有核心路由必须具备与最终布局一致的骨架屏；需要同时覆盖空状态、错误状态、无权限、资源不存在和重试状态，避免只实现理想路径。

## 5. 信息架构

```text
认证
├── 登录
└── 注册

应用
├── 首页 / 快速输入
├── 创作台
├── 作品列表
├── 作品详情
└── 设置

公开页面
└── 私密分享页
```

## 6. 核心输入

### 6.1 文字与歌词

- 创作描述 1–1000 字；
- 原始歌词 1–5000 字；
- 歌词处理要求 0–500 字；
- 支持歌词分段、润色和原稿/修订稿对比；
- 修订结果单独保存，不覆盖原稿。

### 6.2 哼唱与音频

- 浏览器录音支持开始、停止、试听、重录、删除和确认；
- 上传 mp3、m4a、wav、webm；
- 单文件不超过 20MB，时长建议 5–90 秒；
- 显示文件名、大小、时长、播放器和上传进度；
- Melody Analyzer 输出 BPM、音域、旋律轮廓、重复片段、记忆点和置信度；
- 真实分析不可用时使用透明 Mock。

### 6.3 图片与视频

- 图片支持 jpg、jpeg、png、webp，单文件不超过 10MB；
- 视频支持 mp4、mov、webm，单文件不超过 100MB、建议不超过 90 秒；
- 支持预览、删除、替换和设为封面；
- 视频 P0 至少真实上传、播放、持久化并分析首帧或固定关键帧；
- Vision Analyzer 输出主体、场景、色彩、光线、情绪、动态程度、风格、速度、乐器和歌词意象。

### 6.4 输入组合

| ID | 组合 | 默认作用 |
|---|---|---|
| C1 | 文字 | 主题、歌词和风格 |
| C2 | 哼唱/音频 | 旋律、节奏和音高参考 |
| C3 | 图片/视频 | 氛围、配器和歌词意象 |
| C4 | 文字 + 哼唱 | 文字控制语义，哼唱控制旋律 |
| C5 | 文字 + 视觉 | 文字强约束，视觉补充氛围 |
| C6 | 哼唱 + 视觉 | 旋律优先，视觉参与编曲方向 |
| C7 | 文字 + 哼唱 + 视觉 | 多阶段融合，不宣称单模型联合生成 |

空输入不得创建分析或生成任务。

### 6.5 冲突优先级

```text
用户确认的要求
> 原始歌词
> 用户哼唱旋律
> 用户填写的风格描述
> 图片或视频分析结果
> 系统默认值
```

冲突必须展示来源、系统建议、最终处理方式和用户调整入口。

## 7. 首页

- 大型多模态输入框；
- 输入描述或歌词；
- 录制哼唱；
- 上传多个素材；
- 从示例开始；
- 展示最近项目和灵感草稿；
- 提交后创建项目、保存素材、识别组合并跳转创作台；
- 手机端支持“仅保存灵感”。

## 8. 创作台

### 8.1 顶部工具栏

- 项目名称和自动保存状态；
- Provider 选择；
- 输出类型：歌曲 Demo、配乐 Demo、旋律草稿；
- 当前版本；
- 分享和更多操作。

### 8.2 素材构造区

- 文字与歌词、哼唱与音频、图片与视频三个 Tab；
- 每类素材均有原始内容、分析要求、分析状态、分析结果和“参与下一次生成”开关；
- 单一 Provider 不支持某类文件时，素材仍保留并标记直接参与、间接参与、本次未使用或模拟参与。

### 8.3 Creative Brief

包括主题、情绪、风格、速度、乐器、歌词概要、旋律特征、视觉描述、素材证据、冲突和处理优先级。所有可生成字段均允许编辑并保存快照。

### 8.4 Generation Plan

正式生成前展示：

- Provider；
- 每一步能力和输入；
- `real_local`、`real_external` 或 `simulated`；
- Provider 限制；
- 降级路径；
- 用户确认状态。

未确认的计划不得创建生成任务。

### 8.5 生成任务和结果

- 数量可选 1、3、5、10；
- P0 演示至少返回两个候选；
- 展示排队、分析、生成、完成、失败和取消状态；
- 每个候选展示封面、标题、播放器、类型、Provider、执行标签、说明、设为主版本和再次生成；
- 失败时支持重试、切换 Provider、自动降级或透明 Mock。

## 9. 版本

- 每次保存记录父版本、素材快照、Creative Brief、Generation Plan、Provider、参数和 Demo；
- 支持查看历史、切换版本、设置主版本和基于历史版本再次生成；
- P0 使用线性版本链或简单节点树，不实现分支合并；
- 至少支持连续三次生成且版本可追溯。

## 10. 作品与详情

### 10.1 作品列表

- 卡片和列表视图；
- 搜索、时间排序、输入类型筛选、状态筛选和分页；
- 展示封面、标题、简介、更新时间、输入类型、主版本、Demo 数量和分享状态；
- 支持打开、复制、归档和删除。

项目状态：灵感草稿、分析中、待确认、已生成 Demo、协作中、已归档。

### 10.2 作品详情

- 作品信息、主版本播放器和操作区；
- 歌词、评论、版本信息三个 Tab；
- 歌词支持原始/修订切换；
- 时间点评论点击后播放器跳转并高亮附近评论。

## 11. 分享与评论

### 11.1 分享

- 生成不可猜测的私密链接、二维码和访问 Token；
- 选择具体版本；
- 设置有效期和是否允许评论；
- 支持撤回和重新生成 Token；
- 数据库只保存 Token 哈希。

### 11.2 评论

- 普通评论和绑定音频秒数的时间点评论；
- 必须绑定项目、分享链接和具体 Demo 版本；
- 登录用户自动使用账户身份；
- 匿名访客必须填写 1–40 字昵称；
- 评论内容 1–1000 字；
- 评论作者可删除自己的评论，项目所有者可管理项目评论；
- 新评论回流到创作者页面并显示未读状态。

## 12. Provider 与生成出口

- 支持自动路由、Mock Provider、外部 Provider 和用户自定义配置；
- Provider 配置支持新建、查看、编辑、删除、启停、测试连接和设置默认；
- API Key 只在服务端加密保存，列表和响应仅返回掩码；
- 当前没有真实音乐 API Key 时必须使用授权样例音频并显示“模拟生成 · 授权样例音频”；
- 支持复制或下载纯文本、Markdown、JSON 创作包；
- 支持跳转 Mureka、MiniMax 等外部工具并提示费用、版权和隐私由外部平台负责。

## 13. 认证与用户子系统

- Supabase Auth 仅负责邮箱密码认证和 Session；
- 注册成功后建立应用 Profile；
- 未认证用户访问应用路由时跳转登录；
- 已认证用户访问登录/注册时跳转首页；
- 用户可以更新昵称和头像；
- 头像通过腾讯云 COS 保存；
- 密码、JWT、Secret Key 不进入业务数据库和客户端日志。

## 14. 媒体存储

- 腾讯云 COS 为目标对象存储；
- Bucket 默认私有；
- 浏览器通过短时预签名 URL 直传；
- 对象键必须包含环境、用户和项目隔离前缀；
- 上传前校验 MIME、扩展名、文件大小和业务归属；
- 上传完成后由服务端登记并确认对象；
- 下载和播放使用短时签名 URL；
- 删除业务记录时先软删除，媒体清理由显式操作或清理任务处理；
- 本地开发提供不依赖云密钥的 Mock Storage。

## 17. 非功能需求

- TypeScript strict；
- 首屏结构 2 秒内可见，慢请求优先显示 Skeleton；
- API 错误使用稳定错误码，不泄露密钥、SQL 和内部堆栈；
- 上传支持独立进度和可重试；
- 分享页不依赖后台应用 Layout；
- 数据库变更必须使用不可修改的版本化迁移；
- 核心规则具备单元测试，关键闭环具备集成或 E2E 测试；
- 生产构建、类型检查、Lint 和测试作为交付门槛。

## 18. 24 小时止损

允许降低：

- 视频只分析首帧或固定关键帧；
- Analyzer 失败时使用结构化 Mock；
- Router 使用规则表；
- 外部音乐 Provider 只实现 Mock；
- Provider 配置只完成 CRUD 和连接模拟；
- 版本只做线性链；
- Job 使用数据库状态和短轮询，不引入 Redis；
- 分享评论通过刷新或轮询同步，不引入 WebSocket；
- 局部再次生成只模拟参数变化；
- 本地无腾讯云密钥时使用 Mock Storage。

不得降低：真实身份归属、真实数据持久化、媒体上传边界、分享权限、评论版本绑定、执行透明度和响应式主路径。

## 19. 文案与品牌迁移

- 正式产品名统一为 `SongDraft`；
- `inspire2-demo` 仅作为视觉参考，不作为代码或数据模型基线；
- 页面标题、Metadata、Logo 文案、空状态、分享页和邮件提示不得继续出现旧品牌名；
- v0 中虚构的真实 Provider 名称和“真实生成”数据不得直接迁入。

## 20. 发布门槛

- P0-01–26 均有实现或明确透明降级；
- AC-01–15 有验证记录；
- 六条以上授权 Demo 音频可稳定播放；
- HTTPS 环境连续三次完成主路径；
- 手机真机完成注册、录音、扫码、播放和评论；
- 无明文 API Key、COS Secret、JWT 或 Share Token 入库/入日志；
- 保留可运行部署、上一版本备份和演示录屏。
