- - # 音乐灵感记录与 Demo 制作工具 · 产品需求文档

    ## 一、产品定位

    本产品是一款面向音乐制作人、词曲作者及独立音乐创作者的灵感记录工具，以“快速记录、自动整理、项目沉淀”为核心，帮助用户保存录音、音频、图片和文字等碎片化创作素材，并在需要时将灵感继续发展为歌曲 Demo。

    产品以项目作为灵感组织单位。用户可以先记录灵感，再决定新建项目或保存至已有项目；也可以从制作台直接新建或导入项目进行创作。灵感记录是产品主流程，Demo 生成、版本保存、分享和评论属于灵感进一步发展的后续能力。

    核心流程为：

    ```text
    记录灵感 → 保存到项目 → 进入制作台 → 生成创作 Brief → 修改并确认 → 生成 Demo → 保存版本 → 查看详情 → 分享与评论
    ```

    桌面端承担完整项目管理和 Demo 制作，H5 重点承担随时录音、上传素材和保存项目，不在移动端承载复杂创作操作。

    ------

    ## 二、产品页面

    ### 1. 全局布局

    桌面端采用左侧导航栏与右侧主内容区布局，部分页面支持最右侧详情栏。左侧导航栏分为两个分组：第一组包含“灵感记录”“制作台”“创作库”，第二组为“最近项目”，直接展示最近访问的项目名称，点击后进入对应项目的制作台。

    最右侧详情栏用于展示歌曲详情，由页面右侧滑入；详情栏打开后，制作台形成“原料区、成果区、详情栏”三栏布局。详情栏支持进入全屏详情页，全屏详情页使用独立页面布局，不以遮罩弹窗形式覆盖当前页面。

    ### 2. 灵感记录页

    灵感记录页是产品首页，页面核心为快速记录入口。素材类型按使用优先级排列为录音/音频、图片、文本。录音/音频作为默认 Tab，支持浏览器录音和本地音频上传；图片 Tab 支持图片上传和预览；文本 Tab 支持记录歌词、创作描述或临时想法。
  
    用户完成记录后，可以选择“新建项目并保存”或“保存到已有项目”。保存成功后，系统弹窗询问“是否立即使用本项目进行创作”，用户确认后进入制作台，不确认则停留在当前页面。所有记录必须先完成文件或文本持久化，再建立与项目的关联。
  
    ### 3. 制作台

    制作台用于将项目中的灵感整理为创作 Brief 并生成歌曲 Demo。用户可以从灵感记录成功提示进入制作台，也可以直接通过导航进入；直接进入时需要选择导入已有项目或新建项目，未选择项目时制作台以空状态展示。

    制作台采用左右分栏，左侧为原料区，右侧为成果区。左侧包含“文本、歌曲、图片”三个 Tab，分别处理歌词和 Prompt、录音或音频素材、图片素材。三个 Tab 共用底部固定的 Create 按钮，点击后根据当前项目素材生成创作 Brief。

    右侧首先展示创作 Brief，内容由当前项目的文本、歌词、音频、图片和用户要求综合生成。Brief 支持查看、修改和确认，用户点击修改后可编辑全部字段；确认无误后点击生成，调用 MiniMax API 创建歌曲 Demo。生成数量支持选择 1、3、5、10 首，结果以列表形式展示。

    点击生成结果 Item 后，页面最右侧打开歌曲详情栏。用户可以单个保存歌曲，也可以批量选中多个结果保存为历史版本。每个历史版本必须保留当时使用的 Prompt、歌词、音频、图片、创作 Brief 和 Demo 歌曲，保证后续能够恢复和重新应用。

    ### 4. 版本历史
  
    项目产生并保存歌曲版本后，制作台右上角显示历史记录入口。点击后打开版本历史弹窗，弹窗以树状图展示版本之间的父子关系；点击任意节点后，视图自动移动并以该节点为中心展示。
  
    弹窗底部提供“删除”和“应用”两个按钮，未选中节点时均为禁用状态。“删除”为红色危险操作，用于删除当前选中版本；“应用”用于将选中版本中的 Prompt、歌词、音频、图片、Brief 和 Demo 重新载入当前制作台。版本历史属于项目内部，一个项目对应一首歌曲，多个历史版本仍属于同一项目，不在创作库中拆分为多个作品。
  
    ### 5. 创作库
  
    创作库以 Card 形式展示用户已经创建的歌曲项目，每个项目对应一张 Card，展示封面、标题和简介；项目数量较多时支持分页。点击 Card 进入全屏歌曲详情页。
  
    创作库展示的是项目维度，而不是版本维度。一个项目即一首歌曲，即使项目内部存在多个历史版本，创作库中仍只展示一张 Card。
  
    ### 6. 歌曲详情页
  
    歌曲详情页采用上下纵向布局，上方为信息区，下方为内容区。信息区展示歌曲封面、标题、作者信息和描述，右上角提供分享、编辑和历史切换操作。点击编辑后，将当前版本导入制作台继续创作；存在历史版本时显示历史切换入口，用户可以直接切换并查看历史版本，但不进入制作台。
  
    内容区使用 Tab 切换歌词和评论。歌词 Tab 展示当前版本生成的完整歌词。评论 Tab 采用纵向时间轴结构，评论必须绑定具体音频时间点后才能发送，发送后按时间从上到下排列；点击时间节点时，播放器跳转至对应位置。
  
    制作台中的歌曲结果 Item 也可以打开右侧详情栏，详情栏展示与详情页一致的核心信息，并提供“进入全屏详情”操作。
  
    ### 7. 分享页
  
    成品歌曲支持生成分享链接，但分享内容必须经过权限验证。被分享用户首次通过有效链接访问时，系统将其身份加入该作品权限白名单；后续仅白名单用户可以继续访问。未通过鉴权或未加入白名单的用户即使获得链接，也不能查看作品。
  
    被分享用户进入后看到歌曲详情页，只拥有收听和评论权限，不显示分享、编辑、历史切换等作品管理操作。评论区与作品详情页一致，必须基于播放器当前时间点发送评论，并按时间轴展示。
  
    ### 8. H5 页面
  
    H5 仅重点适配灵感记录流程，支持快速录音、上传音频、上传图片、输入文本，以及新建项目或保存到已有项目。记录完成后可以提示用户是否继续在桌面端创作，但移动端不实现完整制作台、版本树和复杂歌曲管理。

    ## 三、产品功能细节
  
    ### 1. 项目与灵感关系
  
    项目是产品的核心组织单位，录音、音频、图片、文本、歌词、Prompt、Brief、生成结果和历史版本均归属于项目。用户记录灵感时不强制提前创建项目，可以在保存阶段新建或选择已有项目。项目删除后，其关联灵感和版本应按照产品删除规则统一处理。
  
    ### 2. 灵感记录
  
    录音支持开始、结束、试听、重录和删除；音频与图片支持上传、预览、替换和删除；文本支持直接编辑。所有素材必须显示保存状态，未完成上传的素材不能进入制作台生成流程。灵感保存成功后，应明确显示所属项目并提供进入制作台入口。
  
    ### 3. 制作原料
  
    文本 Tab 包含 Prompt、歌词及其他创作描述；歌曲 Tab 包含用户录音、上传音频及已有歌曲素材；图片 Tab 包含项目参考图。切换 Tab 不应丢失已填写内容，Create 按钮始终固定在左侧面板底部，并根据当前项目是否存在有效素材决定可用状态。
  
    ### 4. 创作 Brief
  
    Brief 是原始灵感与歌曲生成之间的中间结果，至少需要包含创作主题、歌词、情绪、风格、演唱方式和参考素材说明。Brief 生成后必须允许用户修改，未经用户确认不得直接调用歌曲生成 API。用户修改后的 Brief 应作为本次生成记录的一部分保存。
  
    ### 5. 歌曲生成
  
    生成时支持选择 1、3、5、10 首，生成过程需要展示任务状态和失败提示。生成结果以列表展示，每个 Item 至少包含封面、标题、播放控件、时长和保存操作。用户可以单独保存一个结果，也可以批量保存多个结果；未保存结果不进入正式版本历史。
  
    ### 6. 版本保存与应用
  
    保存版本时必须记录当前 Prompt、歌词、音频、图片、Brief、生成参数和 Demo 文件。应用历史版本时，将该版本的全部创作上下文恢复到制作台，但不自动覆盖当前未保存内容，应先提示用户确认。删除版本后，其他节点关系需要正常保留；如果删除的是当前应用版本，制作台继续保留当前内容，但该版本不再出现在历史树中。
  
    ### 7. 播放与评论
  
    歌曲结果、详情栏、全屏详情页和分享页均使用统一播放器。评论只能在选择具体播放时间后发送，评论记录包含作品、版本、时间点、评论内容和用户信息。切换历史版本后，只展示绑定到该版本的评论，避免不同音频版本的时间点混淆。
  
    ### 8. 分享权限
  
    分享链接本身不等于公开权限。系统需要验证当前访问者身份，并将首次通过有效分享流程进入的用户加入作品白名单。作品拥有者可以查看已授权用户，并支持撤销权限；权限撤销后，该用户无法继续通过历史链接访问。

    ### 9. 最近项目

    左侧导航栏第二分组以灰色小字展示“最近项目”，下方直接显示最近访问的项目名称。点击项目后进入对应制作台并加载项目内容；项目数量过多时仅展示最近若干项，其余项目通过创作库查找。
  
    ### 10. 响应式范围
  
    桌面端支持完整灵感记录、制作台、版本历史、创作库、详情页和分享管理；H5 仅保证灵感记录、项目保存、分享查看、歌曲播放和评论体验。所有复杂编辑和版本管理操作优先在桌面端完成。
